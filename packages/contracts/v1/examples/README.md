# Synthetic wire fixtures

Every JSON file here is synthetic test data. No device was contacted, no evidence artifact exists at these example locators, and no signature or compliance claim is made. Zero/repeated hashes are deliberately test-only. The offline evidence fixture illustrates a shape, not real CIS support. ExecutionCommand is not an authorization token and must never be submitted to live workers.

Regenerate with `python packages/contracts/v1/build_examples.py`. CollectionResult is UNSUPPORTED, Plan is UNSAT, Simulation is UNSUPPORTED and Verification is NOT_FULLY_VERIFIED so unimplemented tools cannot masquerade as successful operations.
