## 2. Shared Component & Design System Audit

- **Buttons & Inputs (`src/components/ui/`):** Built with Radix UI Slot primitives and Tailwind CSS. Focus rings visible with accessible contrast (`focus:ring-2 focus:ring-sky-500`).
- **Data Tables (`table.tsx`):** Wrapped in `overflow-x-auto` with sticky headers and keyboard scrollability.
- **Badges (`badge.tsx`, `StatusBadge.tsx`, `SeverityBadge.tsx`):** Standardized color tokens for Critical (Red), High (Orange), Medium (Amber), Low (Blue), Pass (Emerald), Fail (Red), Not Assessed (Slate), and Error (Purple).
- **Dialogs & Modals (`ConfirmDialog.tsx`):** Radix UI Dialog primitives with focus trapping, Escape key dismiss, and ARIA labels.
- **Error Boundaries (`ErrorBoundary.tsx`):** React error boundary catches uncaught rendering exceptions, prevents full-page crashes, and renders a recoverable error alert.
